## Overview

NeuroFlow (`neuroflow.world`) is a full-stack web platform developed by **three high school students** as a **team hackathon project** for the [INFOMATRIX World](https://www.infomatrix.ro/) competition.

The platform includes:
- **Landing & Ecosystem Hub (`index.html`)** — Main NeuroFlow portal with interactive sections
- **Projects Hub (`projects/`)** — Top projects showcase and community ratings
- **Application (`aplication/`)** — Interactive NeuroFlow web app
- **AI & Community Chat (`chat/`)** — Real-time chat and AI assistant integration
- **News (`news/`)** — Community and tech news feed
- **P2P (`p2p/`)** — Peer-to-peer collaboration module
- **Authentication (`login/`)** — User sign-in and Google OAuth 2.0 flow
- **Ambient Audio (`music/`)** — Focus & relaxation audio tracks (`Anxiety.mp3`, `Calm.mp3`, `Tired.mp3`)
