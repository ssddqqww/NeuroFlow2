# Платформа для общения

Веб-приложение для общения с рейтингом чатов и возможностью создания собственных чатов.

## Функциональность

- Две вкладки: "Топ" и "Чат"
- Создание собственных чатов с категориями
- Рейтинг чатов на основе лайков/дизлайков
- Отображение количества пользователей онлайн
- Возможность редактирования своих сообщений
- Лайки и дизлайки для сообщений
- Фильтрация матерных слов
- Сохранение истории сообщений
- Запоминание последнего посещенного чата

## Установка

1. Убедитесь, что у вас установлен Node.js
2. Клонируйте репозиторий
3. Установите зависимости:
```bash
npm install
```

## Запуск

1. Запустите сервер:
```bash
npm start
```
2. Откройте браузер и перейдите по адресу: http://localhost:3000

## Структура проекта

- `index.html` - основной HTML файл
- `styles.css` - стили
- `js/` - JavaScript файлы
  - `app.js` - основной файл с общей функциональностью
  - `chat.js` - функциональность чата
  - `top.js` - функциональность топ-чатов
- `server.js` - сервер для обработки JSON файлов
- `chats/` - директория для хранения данных чатов
